# Carrotato

Carrotato is a Minecraft Fabric mod for version **1.21**.

## Description
The primary goal of this mod is to add **chili** to Minecraft. Currently, the project is in its early development stages, providing a clean skeleton for further implementation of chili items, crops, and mechanics.

## Requirements
To run or develop this mod, you will need:
*   **Minecraft**: 1.21
*   **Fabric Loader**: >=0.16.10
*   **Java**: 21
*   **Fabric API**: Required at runtime.

## Building from Source
To build the mod from the source code, navigate to the project directory and run the following command:

```bash
./gradlew build
```

The resulting JAR file will be located in `build/libs/`.
